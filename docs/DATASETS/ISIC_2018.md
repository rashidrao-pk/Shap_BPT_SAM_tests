# ISIC 2018

[ISIC 2018](https://challenge.isic-archive.com/data/) gives two tasks that work well together for XAI: Task 3 trains a skin-lesion classifier, and Task 1 supplies expert lesion masks. The classifier here was trained on Task 3, and the explained images come from Task 1.

| | |
| --- | --- |
| Images | Task 1: 2,594 train, 100 validation, 1,000 test |
| Ground truth | One binary lesion mask per image |
| Classifier | EfficientNet-B0 trained on Task 3 / HAM10000, 7 classes |
| Download | 229 MB validation (2.2 GB test, 10.4 GB train), 16 MB checkpoint |
| Licence | Task 1 CC-0; Task 3 and the checkpoint CC BY-NC 4.0 |

## 1. Download the dataset and checkpoint

```bash
python src/scripts/download_datasets.py --dataset isic2018
```

The default is the 100-image validation split, which is enough for a first run. For paper-scale results use `--split test`, then change `validation` to `test` in both paths in `src/configs/ISIC2018_epito.yaml`.

The script does three things after downloading to `/beegfs/home/mrashid/datasets/ISIC2018/raw`:

1. **Downscales images and masks together** into `prepared_1024/<split>/{images,masks}`. Sources reach 6708×4439 pixels (30 MP), while the classifier only sees 320×320. Full-size SAM masks and masked evaluations would be very slow and memory-heavy. Images are saved as PNG, and masks use nearest-neighbour resizing so they stay binary. Change the limit with `--max-side`.
2. **Checks leakage** by comparing the split's image IDs with Task 3 training IDs and printing the overlap.
3. Saves the checkpoint in `checkpoints/isic2018_efficientnet_b0/`, pinned to one commit and verified by SHA-256.

## 2. Why this checkpoint

[adeIaide/skin-lesion-7class-efficientnet](https://huggingface.co/adeIaide/skin-lesion-7class-efficientnet) was chosen because:

- It publishes `config.json` with class order and normalization, so preprocessing is not guesswork.
- It was trained with a lesion-disjoint split, avoiding the same lesion in train and development data.
- Weights are in `safetensors` format, so loading runs no pickled code.
- Its training images share **no image IDs** with Task 1. All 3,694 Task 1 images were compared with Task 3's 10,015 training IDs and none matched.

Reported on its internal split: macro-F1 0.764, balanced accuracy 0.796. There is no independent validation.

Alternatives: [malemehaute/vit-base-ham10000-skin-lesion](https://huggingface.co/malemehaute/vit-base-ham10000-skin-lesion) documents no preprocessing or label order, and [iamhmh/derm-cnn-ham10000](https://huggingface.co/iamhmh/derm-cnn-ham10000) takes 28×28 input, too coarse for region explanations.

## 3. Generate partitions

```bash
python src/scripts/generate_isic2018_partitions.py \
  --config ISIC2018_epito --model sam2 \
  --checkpoint "$SAM2_DIR/checkpoints/sam2.1_hiera_tiny.pt" \
  --sam2-config configs/sam2.1/sam2.1_hiera_t.yaml \
  --device cuda --max-regions 62 --generate_at_least_n_masks 50 \
  --save-partitions sam compact
```

## 4. Explain

```bash
python src/scripts/explanations/OC_ISIC2018.py \
  --config ISIC2018_epito --show-gt --limit 2 \
  --budget 1000 --no-heatmaps --explain_all
```

The runner explains the top predicted class and reports pointing accuracy and best IoU against the lesion mask. GradCAM uses the last EfficientNet feature block. LRP is reported as unsupported.

## Limits on what you can claim

- **Task 1 has no diagnosis labels.** You can test whether the explanation points at the lesion, but not whether the prediction is correct.
- **Domain shift.** Task 1 images differ from HAM10000. Mean top-class confidence was only 0.46 on 12 sampled validation images. Check the confidence of explained predictions, because a low-confidence class gives a weak explanation target.
- Zero ID overlap does not rule out the same lesion appearing under a different ID.
- Direct resizing to 320×320 changes the aspect ratio, so the model sees stretched lesions. This follows the model's own preprocessing.
- A correct lesion location does not mean a clinically valid reason. Models can also use hair, rulers, or dermoscope borders, so inspect attribution outside the mask.
- Research diagnostics only, not for medical use.
