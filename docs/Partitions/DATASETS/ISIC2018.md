## Generate Partitions for `ISIC 2018` Dataset

- [Connect first](../EPITO.md#1-start-a-gpu-session)
- [Download the dataset](../../DATASETS/ISIC_2018.md)
- Download checkpoints: [SAM-1](../../MODELS/SAM1.md), [SAM-2](../../MODELS/SAM2.md)

Run from the repository root on a GPU node. Ground-truth masks are never used to generate partitions.

### Check paths

```bash
python src/scripts/generate_isic2018_partitions.py \
  --config ISIC2018_epito --limit 2 --dry-run
```

### SAM-1

```bash
python src/scripts/generate_isic2018_partitions.py \
  --config ISIC2018_epito \
  --model sam1 \
  --checkpoint "$PROJECT_DIR/checkpoints/sam1/sam_vit_b_01ec64.pth" \
  --sam1-variant vit_b \
  --device cuda \
  --max-regions 62 \
  --generate_at_least_n_masks 50 \
  --save-partitions sam compact \
  --limit 2
```

### SAM-2

```bash
python src/scripts/generate_isic2018_partitions.py \
  --config ISIC2018_epito \
  --model sam2 \
  --checkpoint "$SAM2_DIR/checkpoints/sam2.1_hiera_tiny.pt" \
  --sam2-config configs/sam2.1/sam2.1_hiera_t.yaml \
  --device cuda \
  --max-regions 62 \
  --generate_at_least_n_masks 50 \
  --save-partitions sam compact \
  --limit 2
```

Remove `--limit 2` to process the whole configured split. Repeat the same command to resume: completed images are skipped.

Keep `--save-partitions sam compact`. Saving other stages changes the folder name, so it would no longer match the config or the budget study.

### Choose the partitions for XAI

| Model | Folder |
| --- | --- |
| SAM-1 | `ISIC2018_sam1_vit_b_62_compact-sam_50` |
| SAM-2 | `ISIC2018_sam2_tiny_62_compact-sam_50` |

The config selects SAM-2. To explain SAM-1 partitions, set `data.mask_dir_final` to the SAM-1 folder.

## Preview the first five completed images

```bash
python src/scripts/view_partitions.py \
  --config ISIC2018_epito \
  --limit 5 \
  --methods sam compact \
  --show-gt
```

- Or preview one image by its filename stem:

```bash
python src/scripts/view_partitions.py \
  --config ISIC2018_epito \
  --image-id ISIC_0012255 \
  --methods sam compact \
  --show-gt
```

The preview shows the binary lesion mask.

## Progress

```bash
python src/scripts/check_partition_progress.py --config ISIC2018_epito
```

The config reads the downscaled `prepared_1024/validation` folder, so the expected total is 100. Do not point `image_dir` at `raw/`: images there reach 30 MP. The folder name does not include the split, so use a separate `output.partitions` root when switching to `test`.
