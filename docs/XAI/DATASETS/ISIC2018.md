# ISIC 2018 explanations

Run from the repository root on a GPU node. First [download the dataset](../../DATASETS/ISIC_2018.md), get the checkpoint ([ISIC EfficientNet-B0](../../MODELS/ISIC_EFFICIENTNET.md)), and [generate partitions](../../Partitions/DATASETS/ISIC2018.md). Make sure `data.mask_dir_final` names the generated folder.

## Run

```bash
python src/scripts/explanations/OC_ISIC2018.py \
  --config ISIC2018_epito --show-gt --limit 1 \
  --budget 1000 --no-heatmaps --explain_all
```

The three partition methods share the budget: BPT, BPT+SAM_c, and SAM_c+KernelSHAP. `--explain_all` adds LIME, Shap-AA, LRP, GradCAM, IDG, GradExp, and GradShap, and needs `requirements-xai-all.txt`. Remove `--limit 2` for all completed partitions. Add `--dry-run` to check paths without loading the model.

The checkpoint path comes from `model.checkpoint` in the config. The explained class is the top prediction of the seven diagnoses, fixed for each image. GradCAM uses the last EfficientNet feature block. LRP is not available for this architecture and is reported as unsupported.

## Ground truth

`--show-gt` outlines the expert lesion mask. Results also include pointing accuracy and best IoU. Best IoU picks the best threshold using GT, so it is a diagnostic, not a test score.

## Reading the results

- Task 1 has no diagnosis labels, so you can test where the model looks, not whether its prediction is correct.
- Record the explained class's confidence. It averaged 0.46 on 12 sampled validation images, and a low-confidence class is a weak explanation target.
- Inspect attribution outside the mask: models can use hair, rulers, or dermoscope borders.
- Research diagnostics only, not for medical use.

## Outputs and resume

```text
<output.explanations>/OC_ISIC2018/<partition-folder>/bg_full_B1000/<image-id>/
<output.evaluations>/OC_ISIC2018/<partition-folder>/bg_full_B1000/
```

Repeat the same command to resume: completed images are skipped. `--no-heatmaps` skips individual method images, and keeps the combined plots and numeric results.
